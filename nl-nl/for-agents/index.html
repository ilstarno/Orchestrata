Orchestrata voor je AI-agent

Verbind Orchestrata met je bestaande AI-abonnement en bekijk een leadtoewijzing.

Codex CLI Lokaal geverifieerdClaude CodeCursorGrok BotGrok Build
  1. 01

    Lokale Orchestrata-tool

    Bouw de tool op de computer waar de agent draait.

    cargo build --locked --manifest-path backend/Cargo.toml -p orchestrata-mcp
  2. 02

    Verbinding met Codex CLI

    Registreer Orchestrata en controleer of het actief is.

    codex mcp add orchestrata -- "$ORCHESTRATA_MCP"
codex mcp get orchestrata
  3. 03

    Voorbeeld leadtoewijzing

    Bekijk lead L-001 zonder je CRM te wijzigen.

    Voorbeeldlead
    L-001
    Toegewezen medewerker
    REP-08
    Voorgesteld contact
    CT-001
