Aan de slag met Orchestrata

Kies de kortste weg naar een planningsresultaat: lees een voorbeeld, roep een bestaande server aan of gebruik de solver in uw toepassing.

Wat wilt u doen?

Een uitgewerkt voorbeeld lezen

Bekijk hoe twee taken verschillende middelen krijgen. Er is geen installatie of server nodig.

Lees de handleiding (English)

Een bestaande server aanroepen

Verstuur JSON via HTTP met curl of uw toepassing. Vraag de beheerder om het adres en de toegangsinstructies. De client heeft geen Rust-installatie nodig.

Lees de handleiding (English)

Een bibliotheek in uw toepassing gebruiken

Kies een taalbinding. De SDK laadt de bijpassende native solverbibliotheek in uw proces. De beschikbare pakketten worden uit broncode gebouwd.

Lees de handleiding (English)

Een lokale server starten

Download de openbare broncode, bouw het programma en controleer het eerste antwoord. Hiervoor zijn Rust en Cargo nodig.

Lees de handleiding (English)

Begrippen vóór gereedschap

Rust is de taal waarin de server en solver zijn geschreven. Cargo bouwt Rust-programma’s en beheert hun afhankelijkheden. Een API is de interface die uw programma aanroept; een SDK is een bibliotheek die het importeert.

De website toont voorbeelden en documentatie. Er is geen openbare HTTP-solver op deze site. Gebruik een server van uw team of start er één op uw computer.
