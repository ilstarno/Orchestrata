Aan de slag met Orchestrata.

Voer eerst het toewijzingsvoorbeeld uit de repository uit. Het gebruikt hetzelfde invoerformaat als de lokale HTTP-API.

  • De planningsengine testen
  • Naslag voor CLI en API
  • Planningsvoorbeelden en sjablonen
  • Uitvoeren en implementeren
  • Naslag voor de solver-API (in het Engels)
  • Naslag voor de recepten-API (in het Engels)
  • Naslag voor native SDK’s (in het Engels)
  • De lokale backend instellen en problemen oplossen (in het Engels)

Start de CLI

Kloon het project en gebruik een recente stabiele Rust-toolchain. Voer dit uit in de hoofdmap van de repository:

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

Bekijk de voorbeeldinvoer en het verwachte resultaat (in het Engels).

Start de HTTP-API

In de map backend/:

cargo run -p orchestrata-api

Open een tweede terminal, ook in backend/:

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

De API draait lokaal. Deze site bevat documentatie en draait geen solver.

Wat wordt ondersteund

  • Variabelen met gehele waarden
  • Regels voor verschillende waarden
  • Verboden waardeverschillen
  • Voorkeurswaarden
  • Strafpunten voor harde regels en voorkeuren

De huidige API controleert maximaal 100.000 combinaties. Controleer vóór gebruik of het resultaat aan de harde regels voldoet.
