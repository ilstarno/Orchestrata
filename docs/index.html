Run the CLI

From the repository root with stable Rust:

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

See the example inputs and expected result.

Run the HTTP API

From backend/:

cargo run -p orchestrata-api

In a second terminal in backend/:

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

Run the API on your machine. This site is documentation only.

What it supports

  • Variables with integer domains
  • All-different constraints
  • Unequal offsets
  • Preferred values
  • Hard and soft penalties

The starter API checks up to 100,000 combinations. Verify the hard rules before using a result.
