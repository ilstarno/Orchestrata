Terms before tools

Rust is the language used to build the server and solver. Cargo is Rust’s build and dependency tool. An API is the interface your program calls; an SDK is a library your program imports.

The website shows examples and documentation. It does not provide a public HTTP solve service. Use a server supplied by your team or start one on your own computer.
