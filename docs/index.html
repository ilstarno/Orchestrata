Get started with Orchestrata.

Run the checked-in assignment first. It uses the same problem shape as the local HTTP API.

Run the CLI

Clone the project and use a recent stable Rust toolchain. From the repository root:

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

See the example inputs and expected result.

Run the HTTP API

From the backend/ directory:

cargo run -p orchestrata-api

In another terminal, also under backend/:

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

The API runs locally. This site publishes documentation and does not host a live solver.

What it supports

  • Variables with integer domains
  • All-different constraints
  • Unequal offsets
  • Preferred values
  • Hard and soft penalties

The current API caps exhaustive search at 100,000 combinations. Check that the result satisfies the hard rules before you rely on it.
