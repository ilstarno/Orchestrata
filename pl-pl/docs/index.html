Wywołać istniejący serwer

Wyślij JSON przez HTTP za pomocą curl lub swojej aplikacji. Poproś operatora o adres i instrukcje dostępu. Klient nie wymaga instalacji Rusta.

Czytaj instrukcję (English)

Użyć biblioteki w aplikacji

Wybierz bibliotekę dla swojego języka. SDK ładuje pasującą bibliotekę natywną silnika do procesu aplikacji. Dostępne pakiety buduje się ze źródeł.

Czytaj instrukcję (English)

Uruchomić lokalny serwer

Pobierz publiczny kod, zbuduj program i sprawdź pierwszą odpowiedź. Ta ścieżka wymaga Rusta i Cargo.

Czytaj instrukcję (English)

Najpierw pojęcia

Rust to język, w którym napisano serwer i silnik. Cargo buduje programy Rust i zarządza zależnościami. API to interfejs wywoływany przez program, a SDK to biblioteka, którą program importuje.

Witryna udostępnia przykłady i dokumentację, a nie publiczny serwer obliczeń HTTP. Użyj serwera swojego zespołu albo uruchom własny na swoim komputerze.
