Uruchom CLI

Sklonuj projekt i użyj aktualnego stabilnego zestawu narzędzi Rust. W katalogu głównym repozytorium:

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

Zobacz dane przykładu i oczekiwany wynik (po angielsku).

Uruchom API HTTP

W katalogu backend/:

cargo run -p orchestrata-api

W drugim terminalu, również w katalogu backend/:

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

API działa lokalnie. Ta strona udostępnia dokumentację, ale nie uruchamia silnika.

Obsługiwane funkcje

  • Zmienne o wartościach całkowitych
  • Reguły wymagające różnych wartości
  • Niedozwolone różnice wartości
  • Preferowane wartości
  • Kary za naruszenie reguł i preferencji

Obecne API sprawdza najwyżej 100 000 kombinacji. Przed użyciem wyniku sprawdź, czy spełnia obowiązkowe zasady.
