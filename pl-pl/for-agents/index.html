Orchestrata dla Twojego agenta AI

Połącz agenta, aby przeglądać szablony i przykłady planowania.

Codex CLI Sprawdzone lokalnieClaude CodeCursorGrok BotGrok Build
  1. 01

    Lokalne narzędzie Orchestrata

    Zbuduj je na maszynie, na której działa agent.

    cargo build --locked --manifest-path backend/Cargo.toml -p orchestrata-mcp
  2. 02

    Połączenie z Codex CLI

    Zarejestruj Orchestrata i sprawdź, czy jest włączona.

    codex mcp add orchestrata -- "$ORCHESTRATA_MCP"
codex mcp get orchestrata
  3. 03

    Podgląd przydziału leada

    Zapisany przykład: L-001 przypisano do REP-08. Podgląd niczego nie zapisuje w CRM.

    Przykładowy lead

    Przypisany opiekun
    REP-08
    Proponowany kontakt
