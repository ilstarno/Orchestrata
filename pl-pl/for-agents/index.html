Korzystaj z agenta AI, którego już masz

Zachowaj swoją subskrypcję AI. Połącz agenta i sprawdź przydział kontaktu sprzedażowego.

Codex CLI Sprawdzone lokalnieClaude CodeCursorGrok BotGrok Build
  1. 01

    Przygotuj Orchestratę

    Zbuduj lokalne narzędzie na komputerze, z którego korzysta agent.

    cargo build --locked --manifest-path backend/Cargo.toml -p orchestrata-mcp
  2. 02

    Połącz Codex CLI

    Zarejestruj Orchestratę i sprawdź, czy narzędzie jest aktywne.

    codex mcp add orchestrata -- "$ORCHESTRATA_MCP"
codex mcp get orchestrata
  3. 03

    Sprawdź wynik

    Wypróbuj przykład L-001. Dane w CRM pozostaną bez zmian.

    Przykładowy lead
    L-001
    Przypisany opiekun
    REP-08
    Proponowany kontakt
    CT-001
