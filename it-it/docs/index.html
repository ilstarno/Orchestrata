Primi passi con Orchestrata.

Esegui prima l’esempio di assegnazione nel repository. Usa lo stesso formato di input dell’API HTTP locale.

  • Valuta il motore di pianificazione
  • Riferimento per CLI e API
  • Esempi e modelli di pianificazione
  • Avvio e distribuzione
  • Riferimento API del motore (in inglese)
  • Riferimento API delle ricette (in inglese)
  • Riferimento degli SDK nativi (in inglese)
  • Configurare il backend locale e risolvere problemi (in inglese)

Avvia la CLI

Clona il progetto e usa una versione stabile recente degli strumenti Rust. Dalla cartella principale del repository:

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

Vedi i dati dell’esempio e il risultato atteso (in inglese).

Avvia l’API HTTP

Dalla cartella backend/:

cargo run -p orchestrata-api

In un altro terminale, sempre in backend/:

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

L’API viene eseguita in locale. Il sito pubblica la documentazione e non ospita un motore attivo.

Funzioni supportate

  • Variabili con valori interi
  • Vincoli che impongono valori distinti
  • Differenze tra valori non ammesse
  • Valori preferiti
  • Penalità per vincoli obbligatori e preferenze

L’API attuale verifica al massimo 100.000 combinazioni. Prima di usare il risultato, controlla che rispetti le regole obbligatorie.

Note sul motore su GitHub (in inglese)

Che cosa deve pianificare?

Descriva le attività, le persone o le attrezzature coinvolte, le regole inderogabili e come pianifica il lavoro oggi. Usi un esempio fittizio o anonimizzato. Non invii dati dei clienti.
