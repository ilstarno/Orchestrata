Esegui Orchestrata in locale (in inglese)

Per sviluppatori

Avvia la CLI

Dalla radice del repository, con Rust stabile:

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

Vedi i dati dell’esempio e il risultato atteso (in inglese).

Avvia l’API HTTP

Dalla cartella backend/:

cargo run -p orchestrata-api

In un secondo terminale, in backend/:

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

Esegui l’API sul tuo computer. Questo sito contiene solo la documentazione.

Funzioni supportate

  • Variabili con valori interi
  • Vincoli che impongono valori distinti
  • Differenze tra valori non ammesse
  • Valori preferiti
  • Penalità per vincoli obbligatori e preferenze

L’API di base esamina fino a 100.000 combinazioni. Verifica i vincoli obbligatori prima di usare il risultato.
