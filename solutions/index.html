Planning use cases

Start with the decisions people make: who covers a shift, which technician takes a job, or which van can handle a load. Each example defines one problem and shows what the current model leaves out.

Who can cover this shift?

Start with the people qualified and available for each overlapping assignment. Treat coverage as a requirement and preferred assignments as a separate objective.

Beyond the example: A full roster also needs hours, breaks, rest periods, and coverage across many shifts.

Which technician should take each job?

List the technicians who can handle each job. For overlapping jobs, require distinct technicians and prefer a familiar technician where it does not break coverage.

Beyond the example: Travel time, visit sequence, and variable appointment windows are beyond the reference example.

Which van can handle the job?

Use available vehicles that can carry each job’s load. Overlapping jobs must use distinct vehicles, even if the same van is preferred twice.

Beyond the example: This is fixed-window allocation, not capacity-aware routing or production sequencing.
