Choose who takes each job or where work should happen. Define the rules that must hold, then use preferences to pick among assignments that fit.

Run the assignment exampleRead the documentation

How the example works

  1. List the choices. Either job can use resource 0 or 1.
  2. Set a rule and a preference. The jobs must use different resources. Job A prefers resource 1.
  3. Check the assignments. The solver checks all four combinations. The result satisfies both the rule and the preference.

Start with a small planning problem

The Rust command line tool and local HTTP API handle small integer-domain problems. They are a starting point for evaluation, not a production scheduler.
