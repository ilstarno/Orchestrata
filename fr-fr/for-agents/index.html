Utilisez l’agent IA que vous avez déjà

Gardez votre abonnement IA. Connectez votre agent et consultez une attribution de prospect.

Codex CLI Vérifié en localClaude CodeCursorGrok BotGrok Build
  1. 01

    Préparez Orchestrata

    Compilez l’outil local sur l’ordinateur utilisé par votre agent.

    cargo build --locked --manifest-path backend/Cargo.toml -p orchestrata-mcp
  2. 02

    Connectez Codex CLI

    Enregistrez Orchestrata et vérifiez qu’il est activé.

    codex mcp add orchestrata -- "$ORCHESTRATA_MCP"
codex mcp get orchestrata
  3. 03

    Consultez le résultat

    Essayez avec le prospect L-001. Rien n’est écrit dans votre CRM.

    Prospect test
    L-001
    Responsable désigné
    REP-08
    Contact proposé
    CT-001
