Premiers pas avec Orchestrata.

Exécutez d’abord l’exemple d’affectation du dépôt. Il utilise le même format d’entrée que l’API HTTP locale.

Choisir le guide adapté à votre environnement

Les guides testent des versions différentes du code. Utilisez la version indiquée dans le guide choisi. Les tests ne montrent pas que ces versions fonctionnent ensemble.

Référence des SDK natifs (en anglais)

Exécution et déploiement

Lancer la CLI

Clonez le projet et utilisez une version stable récente des outils Rust. À la racine du dépôt :

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

Consultez les données de l’exemple et le résultat attendu (en anglais).

Lancer l’API HTTP

Dans le répertoire backend/ :

cargo run -p orchestrata-api

Dans un autre terminal, toujours dans backend/ :

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

L’API s’exécute en local. Ce site publie la documentation et n’héberge pas de solveur.

Fonctions prises en charge

  • Variables à valeurs entières
  • Contraintes de valeurs distinctes
  • Écarts de valeurs interdits
  • Valeurs préférées
  • Pénalités pour les règles et les préférences

L’API actuelle vérifie au maximum 100 000 combinaisons. Avant d’utiliser le résultat, vérifiez qu’il respecte les règles obligatoires.
