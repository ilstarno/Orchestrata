Utiliser une bibliothèque dans votre application

Choisissez une liaison pour votre langage. Le SDK charge la bibliothèque native correspondante dans votre processus. Les paquets disponibles se construisent à partir des sources.

Lire le guide (English)

Démarrer un serveur local

Téléchargez les sources publiques, compilez le programme et vérifiez la première réponse. Ce parcours nécessite Rust et Cargo.

Lire le guide (English)

Les termes avant les outils

Rust est le langage du serveur et du solveur. Cargo compile les programmes Rust et gère leurs dépendances. Une API est l’interface appelée par votre programme ; un SDK est une bibliothèque qu’il importe.

Le site présente des exemples et la documentation. Il ne fournit pas de service public de résolution HTTP. Utilisez un serveur de votre équipe ou démarrez-en un sur votre ordinateur.
