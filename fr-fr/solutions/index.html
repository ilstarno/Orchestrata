Voyez comment Orchestrata propose un plan

Orchestrata répartit le travail entre les personnes, les véhicules ou les équipements disponibles. Il tient compte de vos règles et vous montre ce qui reste à trancher.

Partez d’une situation de votre équipe

  • Couvrir un créneau après une absence

    Comparez deux plannings et voyez qui peut reprendre le créneau.

  • Trouver le bon technicien

    Vérifiez qui est disponible, qui a les compétences et quelles interventions restent à couvrir.

  • Organiser les livraisons

    Voyez quels arrêts entrent dans les tournées et lesquels restent en attente.

Sept autres décisions de planification
  • Répartir les contrôles de paiement

    Confiez les dossiers à une personne disponible, sans sauter les étapes de contrôle.

  • Planifier les inspections après sinistre

    Répartissez les tâches déjà approuvées entre les équipes disponibles.

  • Attribuer les prospects entrants

    Choisissez qui répond aux prospects selon les règles de l’équipe.

  • Attribuer les quais (en anglais)

    Vérifiez quels quais conviennent au véhicule et au créneau.

  • Répartir le fret (en anglais)

    Comparez les départs possibles selon les horaires et les places disponibles.

  • Couvrir les files d’assistance (en anglais)

    Voyez qui peut prendre le relais pendant une pause.

  • Attribuer les portes (en anglais)

    Choisissez des portes compatibles pour des vols qui se chevauchent.
