Utilisez l’agent IA que vous avez déjà

Gardez votre abonnement IA. Un agent qui peut accéder à votre service HTTP peut soumettre des problèmes de planification à Orchestrata et vous présenter les résultats.

Voir comment connecter un agent (en anglais)

Ce que vous indiquez et ce que vous obtenez

  1. Listez les tâches et les options autorisées. Précisez quelles personnes, quels véhicules ou quels équipements peuvent prendre en charge chaque tâche.
  2. Séparez les règles impératives des préférences. Évitez d’abord les doubles affectations. Favorisez les choix préférés lorsqu’ils respectent les règles.
  3. Examinez le résultat. Vérifiez les affectations et les préférences satisfaites par le plan.
