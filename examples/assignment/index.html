Two-job resource assignment

Give two overlapping jobs different resources. Use resource 1 for Job A if the plan allows.

Problem definition

Both jobs need a resource at the same time. Give Job A its preferred resource and Job B the other one.

Technical files and commands
{
  "variables": [
    {
      "name": "job_a",
      "domain": [
        0,
        1
      ]
    },
    {
      "name": "job_b",
      "domain": [
        0,
        1
      ]
    }
  ],
  "constraints": [
    {
      "kind": "all_different",
      "variables": [
        0,
        1
      ],
      "hard_weight": 1
    },
    {
      "kind": "prefer_value",
      "variable": 0,
      "value": 1,
      "soft_weight": 3
    }
  ]
}
cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

Open the input file on GitHub

Why this plan wins

Two of the four assignments use different resources. Only [1, 0] also fits the preference. Both scores are zero.

Blocked: [0, 0] would double-book the same resource.
