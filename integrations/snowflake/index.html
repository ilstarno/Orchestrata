What this connector does

Read a small approved planning view without opening arbitrary database queries.

Data in scope

Read bounded approved planning views through the SQL API. The connector selects the agreed view rather than accepting free-form SQL.

Reads and changes

Read the approved planning view within the agreed row and response limits.

Access to arrange

Ask the database owner to provide the approved view and a read-scoped identity. Agree row and response limits before using it in a pilot.

What to check before relying on it

Keep the approved view small enough for a complete bounded response. Agree a narrower view with the database owner when more data is needed.

Plan a scoped pilot

Start with the records and decision described above. Agree the permitted data, account access and review owner before any connection. Use the listed records, permissions and decision to define the scope.
