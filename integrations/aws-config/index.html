AWS Config

Use recorded cloud inventory to scope operational work.

Data, actions and access

AWS Config query results

View the official source documentation

The official example shows EBS inventory in a query result. Orchestrata reads bounded resource inventory, including EC2 and EBS. Select the approved resource scope; inventory observations do not authorize infrastructure changes.

What this connector does

Use recorded cloud inventory to scope operational work.

Data in scope

Read bounded resource inventory, including EC2 instances and EBS volumes, within the approved account and region.

Reads and changes

Read recorded resource inventory for an operational review. Infrastructure changes follow your existing change process.

Access to arrange

Approve the AWS account, region and inventory permissions. Start with the resource types needed for a specific maintenance or ownership review.

What to check before relying on it

Inventory describes recorded resources, not live application health or an approved maintenance window. Check current operational state separately.

Plan a scoped pilot

Start with the records and decision described above. Agree the permitted data, account access and review owner before any connection. Use the listed records, permissions and decision to define the scope.
