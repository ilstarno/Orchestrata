Use the AI agent you already have

Bring your own AI subscription. Connect a client you already use, then check a recorded Orchestrata result with sample data.

Connect an agent and check one result

This example runs on built-in sample records. It needs no Orchestrata account, network port, or CRM credentials. Your agent client can still require its own account or workspace approval.

  1. Build the local tool

    Use Cargo in a Linux or macOS shell. These commands pin the platform revision with the lead tools.

    gh repo clone ilstarno/Orchestrata
cd Orchestrata
git switch --detach c841b36ad4d8fd1f246a5cefe96a05a72d8784fe
cargo build --locked --manifest-path backend/Cargo.toml -p orchestrata-mcp
ORCHESTRATA_MCP="$PWD/backend/target/debug/orchestrata-mcp"
test -x "$ORCHESTRATA_MCP"

    The client starts the executable. Don’t run it separately or add a transport flag to it.

  2. Connect your client

    Choose the setup below. Use an absolute path to the binary on the machine where the client runs.

    CodexClaude CodeGrok Bot / BuildCursor

  3. Check the answer

    Use list_lead_examples, then preview_lead_example with lead_id L-001. Show the outcome, assigned representative and contact ID. Do not create a record or send it anywhere.
    Sample lead
    L-001
    Outcome
    Would create a contact
    Representative
    REP-08
    Sample contact
    CT-001

    The tool reports created for this case. No record is written. See the recorded tool response.

    Check without an AI account

    Download the local verifier. Put it in the current folder and run:

    python3 verify_mcp.py "$ORCHESTRATA_MCP" --revision c841b36ad4d8fd1f246a5cefe96a05a72d8784fe

Set up your client

Codex CLI

Register the executable where Codex runs, check the configuration, then use /mcp in an active session. Registration and listing were run locally. Sending a prompt requires model access.

codex mcp add orchestrata -- "$ORCHESTRATA_MCP"
codex mcp list
codex mcp get orchestrata
Official Codex MCP setup
Claude Code

Run these commands in the project where you’ll use Claude Code. The entry is scoped to you in that project. Open Claude Code from the same folder and check /mcp.

claude mcp add --transport stdio --scope local orchestrata -- "$ORCHESTRATA_MCP"
claude mcp list
claude mcp get orchestrata
Official Claude Code MCP setup
Grok Bot and Grok Build

Grok Bot: The desktop app connects to a separate cloud computer. Build the tool in that approved environment. In Connect apps → Add a custom connector, choose Command and enter the cloud-side executable path with no arguments. Check the Installed list and your account’s connector-sharing rules. A path on your laptop won’t work there.

Official Grok Bot setup and UI

Grok Build CLI: Register the binary in the environment running grok. Open /mcps in the CLI to check the available tools.

grok mcp add orchestrata -- "$ORCHESTRATA_MCP"
grok mcp list
grok mcp doctor orchestrata
Official Grok Build MCP setup
Cursor desktop or CLI

Merge the entry into your project’s .cursor/mcp.json. Replace the example path. Don’t overwrite other tool entries. In the local CLI, check with agent mcp list and agent mcp list-tools orchestrata.

{
  "mcpServers": {
    "orchestrata": {
      "type": "stdio",
      "command": "/absolute/path/to/Orchestrata/backend/target/debug/orchestrata-mcp",
      "args": []
    }
  }
}
Official Cursor MCP setup

Claude Code, Cursor and Grok setup steps follow the vendor documentation. Their signed-in interfaces were not part of the local verification. See the vendor links for their current screens.

Read the local Solve API guide

What the local connection does

The sample tools list recipe inputs and preview lead decisions. This interface does not run a solve or write records. Use HTTP separately when you want an assignment.

Access and privacy

A chat subscription may not include API access. A cloud-only agent cannot reach a service on your workstation automatically. Your client or administrator controls what can run, and a prompt may still go to a hosted model.

This website does not host the solver or an MCP endpoint. Use only sample or anonymized input for a first run.
