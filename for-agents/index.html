Use the AI agent you already have

Bring your own AI subscription. Keep the provider and plan you already use. Your agent can prepare a planning problem, and Orchestrata can calculate an assignment for you to review.

Run a planning problem over HTTP

Use an agent that can make HTTP requests and reach the Orchestrata process you run. Start with a sample two-job example. Supply the eligible choices and required rules, send the JSON to POST /api/v1/solve, and check the returned assignments and hard-rule score before using the result.

Read the local Solve API guide

Explore recipes through local MCP

If your agent can launch local MCP servers over standard input and output, the local review build can list recipes, describe their fields, and retrieve synthetic example inputs. This interface does not run a solve. Use HTTP separately when you want an assignment.

See the local recipe tools and commands

What you need

  • An agent that can reach your local HTTP service or supports local MCP, depending on the task.
  • Permission from your AI provider, workspace, or administrator to use that kind of tool.
  • Sample or anonymized input for the first run.

Orchestrata does not require another model subscription or include provider credits. A chat subscription may not include API access, and a cloud-only agent generally cannot reach a service on your workstation.

This website does not host the solver or an MCP endpoint.

Tell us what you need to plan

Describe the jobs, people or equipment involved, the rules that cannot change, and how you plan the work today. Use a sample or anonymized example. Do not send customer records.
