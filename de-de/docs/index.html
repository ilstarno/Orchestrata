Wählen Sie den kürzesten Weg zu einem Planungsergebnis: ein Beispiel lesen, einen vorhandenen Server aufrufen oder den Solver in Ihre Anwendung einbinden.

Anleitung lesen (English)

Einen vorhandenen Server aufrufen

Senden Sie JSON über HTTP mit curl oder Ihrer Anwendung. Fragen Sie den Betreiber nach Adresse und Zugang. Auf dem Client ist keine Rust-Installation nötig.

Anleitung lesen (English)

Eine Bibliothek in Ihrer Anwendung nutzen

Wählen Sie eine Sprachbindung. Das SDK lädt die passende native Solver-Bibliothek in Ihren Prozess. Die verfügbaren Pakete werden aus dem Quellcode gebaut.

Anleitung lesen (English)

Einen lokalen Server starten

Laden Sie den öffentlichen Quellcode, bauen Sie das Programm und prüfen Sie die erste Antwort. Dafür brauchen Sie Rust und Cargo.

Anleitung lesen (English)

Begriffe vor Werkzeugen

Rust ist die Sprache, in der Server und Solver geschrieben sind. Cargo ist das Werkzeug zum Bauen und Verwalten der Abhängigkeiten. Eine API ist die Schnittstelle, die Ihr Programm aufruft; ein SDK ist eine Bibliothek, die es einbindet.

Die Website zeigt Beispiele und Dokumentation. Sie stellt keinen öffentlichen HTTP-Solver bereit. Nutzen Sie einen Server Ihres Teams oder starten Sie einen auf Ihrem Computer.
