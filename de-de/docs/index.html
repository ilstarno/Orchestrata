Erste Schritte mit Orchestrata.

Führen Sie zuerst das Zuordnungsbeispiel aus dem Repository aus. Es verwendet dasselbe Eingabeformat wie die lokale HTTP-API.

  • Planungs-Engine testen
  • CLI- und API-Referenz
  • Planungsbeispiele und Vorlagen
  • Starten und bereitstellen
  • Referenz zur Solver-API (auf Englisch)
  • Referenz zur Rezept-API (auf Englisch)
  • Referenz für native SDKs (auf Englisch)
  • Lokales Backend einrichten und Fehler beheben (auf Englisch)

CLI starten

Klonen Sie das Projekt und verwenden Sie eine aktuelle stabile Rust-Toolchain. Führen Sie im Stammverzeichnis des Repositorys Folgendes aus:

cd backend
cargo run -p orchestrata-cli -- examples/assignment.json

Siehe Beispieleingaben und das erwartete Ergebnis (auf Englisch).

HTTP-API starten

Im Verzeichnis backend/:

cargo run -p orchestrata-api

In einem zweiten Terminal, ebenfalls in backend/:

curl -fsS http://127.0.0.1:3000/api/v1/solve \
  -H "Content-Type: application/json" \
  --data-binary @examples/assignment.json

Die API läuft lokal. Diese Website stellt die Dokumentation bereit und betreibt keinen Solver.

Unterstützte Funktionen

  • Variablen mit ganzzahligen Werten
  • Regeln für verschiedene Werte
  • Verbotene Wertdifferenzen
  • Bevorzugte Werte
  • Strafpunkte für harte und weiche Regeln

Die aktuelle API prüft höchstens 100.000 Kombinationen. Kontrollieren Sie vor der Verwendung, ob das Ergebnis die festen Regeln einhält.
